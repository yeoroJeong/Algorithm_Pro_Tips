A형 실전 치트시트

정현수의 알고리즘 스터디 저장소에 올라간 풀이를 직접 읽고, 다시 풀 때 바로 떠올려야 할 상태·순서·원복 포인트만 압축했습니다. 공식 D3 문제와 모의 SW 역량테스트를 함께 묶었습니다.

현재 풀이 기준: 공식 D3 2문제(1209, 1244), 공식 D4 표기 풀이 0문제, 모의 SW 역량테스트 10문제. 등급보다 실제 A형 출제 패턴에 맞춰 정리했습니다.

풀이 12문제, 한 줄로 다시 보기

카드는 실제 제출 코드의 핵심 선택과 다음번 보완점을 함께 보여줍니다.

D3구현

1209 · Sum

행 → 열 → 두 대각선 합을 독립적으로 계산해 최댓값을 갱신.

잘한 점 계산 축을 분리해 누락을 막음.
다음엔 100 고정값을 상수로 묶고 대각선은 한 for문으로 단순화.
D3백트래킹

1244 · 최대 상금

모든 두 자리 교환을 탐색하되 visited[교환횟수]로 같은 깊이의 중복 상태 제거.

핵심 같은 숫자라도 남은 교환 횟수가 다르면 다른 상태다.
MOCKDFS·DP

1952 · 수영장

월별로 1일·1개월·3개월권을 선택하고 1년권을 초기 상한으로 둔다.

핵심 3개월권은 month+3. 12개월뿐이라 DFS도 충분하고 DP로도 즉시 전환 가능.
MOCKDFS·원복

1949 · 등산로 조성

모든 최고점에서 시작하고, 공사 1회 사용 여부를 상태에 포함.

핵심 다음 칸은 현재 높이-1까지만 깎으면 충분. 높이와 visited를 둘 다 원복.
MOCK백트래킹

1767 · 프로세서 연결

가장자리 코어를 제외하고 4방향 연결 + 연결하지 않는 분기까지 탐색.

중요 목적함수는 코어 수 최대가 1순위, 전선 길이 최소가 2순위. 남은 코어로 최대 코어 수를 못 넘으면 가지치기.
MOCK시뮬레이션

4013 · 특이한 자석

맞닿은 극을 회전 전에 비교하고 전파 여부를 저장한 뒤 실제 회전.

핵심 판정 먼저, 변경 나중. 테스트케이스마다 4개 deque를 clear.
MOCKDFS

4008 · 숫자 만들기

연산자 개수를 상태로 들고 하나 쓰고 재귀한 뒤 반드시 복구.

핵심 첫 숫자를 누적값으로 두고 index 1부터. C++ 정수 나눗셈 규칙 확인.
MOCK방향 DFS

2105 · 디저트 카페

우하→좌하→좌상→우상 순서를 고정하고 현재 방향 유지 또는 다음 방향만 허용.

핵심 시작 디저트도 방문 처리. 출발점 복귀는 최소 4칸일 때만 인정.
MOCKDFS+시뮬

5656 · 벽돌 깨기

열 선택 → 연쇄 폭발 → 중력 → 다음 구슬 순으로 보드를 분기별 복사.

다음엔 남은 벽돌 0이면 즉시 종료. 중력은 각 열을 아래부터 write pointer로 압축하면 더 안전.
MOCK문자열·Set

5658 · 보물상자 비밀번호

N/4 길이로 자르고, 중복되는 회전 전까지만 돌며 16진수를 변환해 내림차순 set에 저장.

핵심 회전은 총 N/4 상태. 전역 deque와 set은 테스트마다 clear.
MOCK조건 구현

4014 · 활주로 건설

행과 열을 같은 1차원 검사 함수로 보고, 높이 차 1과 연속 X칸을 확인.

다음엔 좌표 합을 set key로 쓰기보다 길이 N의 used 배열로 경사로 중복을 표시하면 경계가 선명.
MOCK완전탐색

2117 · 홈 방범 서비스

모든 중심과 서비스 크기를 보며 맨해튼 거리 안의 집 수와 운영 비용을 비교.

공식 비용 K²+(K-1)². 집 좌표만 모아 돌면 격자 전체를 매번 훑지 않아도 된다.

DFS·백트래킹 공통 골격

1244, 1949, 1767, 4008, 2105, 5656에 반복해서 등장했습니다.

void dfs(int depth, State state) {
    if (finished(depth, state)) {
        updateAnswer(state);
        return;
    }

    if (cannotBeatBest(state)) return;

    for (Choice ch : choices(state)) {
        if (!possible(ch, state)) continue;
        apply(ch, state);      // 선택
        dfs(depth + 1, state); // 재귀
        undo(ch, state);       // 원복
    }
}

구현·시뮬레이션 순서 고정

변경 전에 판정하고, 한 단계의 모든 효과를 끝낸 뒤 다음 단계로 갑니다.

01 상태 복사분기마다 독립 보드가 필요한지 결정
02 판정회전·이동 전 상태로 전파 조건 계산
03 변경폭발·회전·전선 설치를 한 번에 적용
04 후처리중력·압축·점수 계산
05 원복공유 상태라면 변경한 모든 값을 되돌림
