B형

문제를 읽고 알고리즘을 고르는 A형 치트시트

외운 코드를 먼저 떠올리지 않습니다. 입력 크기로 가능한 시간복잡도를 정하고, 문제 문장에서 요구하는 답과 상태 변화를 찾아 알고리즘을 선택한 뒤 최소 템플릿만 꺼내 쓰세요.

1제한으로 불가능한 풀이 제거
2요구값으로 후보 알고리즘 선택
3상태와 종료 조건을 종이에 작성
4아래 C++ 최소 코드에 문제 조건 결합

문제를 보면 이 순서로 고른다

위에서부터 답하면 대부분의 A형 후보가 좁혀집니다.

1

가능한 선택을 전부 해봐도 되는가?

N이 작고 순열·조합·배치·선택 결과의 최댓값/최솟값을 구한다.

→ 완전탐색 · 백트래킹
2

격자·그래프를 따라 이동하는가?

연결 여부/모든 경로면 DFS, 가중치 없는 최소 이동 횟수면 BFS.

→ DFS · BFS
3

같은 작은 문제가 반복되는가?

i번째까지의 최적값이 이전 결과들로 결정되고 상태 수가 제한된다.

→ DP · 메모이제이션
4

구간 합을 여러 번 묻는가?

배열/격자는 고정인데 서로 다른 구간의 합을 반복해서 계산한다.

→ 누적합
5

답 X가 가능한지 판정할 수 있는가?

X가 가능하면 그보다 작거나 큰 값도 한쪽 방향으로 가능하다.

→ 매개변수 탐색
6

가중치가 있는 최소 비용 경로인가?

간선 비용이 모두 0 이상이며 한 시작점에서 최단 거리를 구한다.

→ 다익스트라
7

합치기와 같은 집합 판별이 반복되는가?

두 원소의 연결 여부를 빠르게 묻고 연결 관계를 계속 추가한다.

→ Union-Find
8

연속 구간을 늘리고 줄이는가?

양수/비음수 배열에서 연속 구간의 길이·합 조건을 만족시킨다.

→ 투 포인터 · 슬라이딩 윈도우
9

규칙을 그대로 재현하는 문제인가?

회전·이동·충돌·폭발 등 시간 순서가 명확하고 상태가 계속 변한다.

→ 시뮬레이션
10

지금의 최선이 미래 선택을 해치지 않는가?

정렬 후 매 순간 최선 하나를 골라도 최적해가 유지됨을 설명할 수 있다.

→ 그리디 (증명 먼저)

입력 제한으로 먼저 거르기

대략 1초에 1억 번보다 여유 있게 잡는 빠른 기준입니다.

입력 크기먼저 검토할 복잡도대표 후보
N ≤ 10O(N!), O(2ᴺ)순열, 부분집합, 백트래킹
N ≤ 20O(2ᴺ)부분집합, 비트마스킹
N ≤ 100O(N³)3중 반복, 플로이드-워셜
N ≤ 1,000O(N²)모든 쌍 비교, 2차원 DP

C++ 핵심 템플릿

완성 코드가 아니라 문제 조건을 끼워 넣을 최소 골격입니다.

A형 핵심O(분기^깊이)

백트래킹

보이는 말
모든 순서, 배치, 선택, 최대/최소
선택 조건
전체 경우가 제한 안에 있고 중간에 불가능한 분기를 자를 수 있다.
실수 방지
선택 → 재귀 → 원복을 한 묶음으로 쓴다. ‘선택 안 함’도 분기인지 확인.
최소 코드 열기
bool used[MAX_N];
int choice[MAX_N];

void dfs(int depth) {
    if (depth == M) {
        updateAnswer(choice);
        return;
    }
    for (int i = 0; i < N; ++i) {
        if (used[i]) continue;
        used[i] = true;
        choice[depth] = i;
        dfs(depth + 1);
        used[i] = false;
    }
}
A형 핵심그래프O(V+E)

DFS

보이는 말
연결된 영역 수, 경로 존재, 끝까지 탐색
선택 조건
최단 거리보다 한 경로를 깊게 탐색하거나 모든 연결 요소를 확인한다.
실수 방지
방문 시점을 재귀 호출 전으로 고정. 경로마다 방문 해제가 필요한 문제인지 구분.
격자 DFS 최소 코드
int dy[4] = {-1, 1, 0, 0};
int dx[4] = {0, 0, -1, 1};
bool visited[MAX_N][MAX_M];

void dfs(int y, int x) {
    visited[y][x] = true;
    for (int d = 0; d < 4; ++d) {
        int ny = y + dy[d], nx = x + dx[d];
        if (ny < 0 || ny >= N || nx < 0 || nx >= M) continue;
        if (visited[ny][nx] || board[ny][nx] == 0) continue;
        dfs(ny, nx);
    }
}
A형 핵심그래프O(V+E)

BFS

보이는 말
최소 이동 횟수, 가장 빠른 시간, 가까운 순서
선택 조건
한 번의 이동 비용이 모두 같고 시작점에서 최단 거리를 구한다.
실수 방지
큐에 넣을 때 방문 처리해야 중복 삽입을 막는다. 시작 거리 초기화 확인.
격자 BFS 최소 코드
int dy[4] = {-1, 1, 0, 0};
int dx[4] = {0, 0, -1, 1};
vector<vector<int>> dist(N, vector<int>(M, -1));
queue<pair<int,int>> q;

q.push({sy, sx});
dist[sy][sx] = 0;
while (!q.empty()) {
    auto [y, x] = q.front(); q.pop();
    for (int d = 0; d < 4; ++d) {
        int ny = y + dy[d], nx = x + dx[d];
        if (ny < 0 || ny >= N || nx < 0 || nx >= M) continue;
        if (dist[ny][nx] != -1) continue;
        if (board[ny][nx] == 0) continue;
        dist[ny][nx] = dist[y][x] + 1;
        q.push({ny, nx});
    }
}
A형 핵심규칙 구현

시뮬레이션

보이는 말
회전, 이동, 충돌, 폭발, 동시에, K초 후
선택 조건
주어진 규칙을 시간 순서대로 재현하면 답이 나온다.
실수 방지
같은 시각의 판정과 변경을 분리한다. 변경 중인 보드를 다음 판정에 쓰지 않는다.
한 턴 최소 코드
for (int turn = 0; turn < K; ++turn) {
    vector<Change> changes;

    // 1. 현재 상태만 보고 모든 변화 수집
    for (auto& obj : objects)
        changes.push_back(decide(obj));

    // 2. 수집한 변화를 한꺼번에 적용
    for (auto& change : changes)
        apply(change);

    // 3. 충돌/삭제/점수 등 후처리
    cleanup();
}
A형 핵심보통 O(N log N)

그리디

보이는 말
가장 빨리 끝나는, 가장 작은 것부터 선택
선택 조건
현재 선택을 포함하는 최적해가 항상 존재함을 교환 논리로 설명할 수 있다.
실수 방지
‘최소/최대’라는 단어만으로 고르지 않는다. 정렬 기준과 선택의 안전성을 먼저 증명한다.
회의 선택 예시 코드
// {끝 시간, 시작 시간} 순으로 정렬
sort(meetings.begin(), meetings.end());

int count = 0, lastEnd = -1;
for (auto [end, start] : meetings) {
    if (start < lastEnd) continue;
    ++count;
    lastEnd = end;
}
상태 재사용O(상태×전이)

DP

보이는 말
방법의 수, i번째까지 최댓값/최솟값
선택 조건
큰 문제의 답이 더 작은 상태의 답으로 표현되고 같은 상태가 반복된다.
실수 방지
먼저 dp 상태의 의미를 한 문장으로 쓴다. 초기값과 계산 순서가 점화식보다 중요하다.
1차원 DP 최소 코드
const int INF = 1e9;
vector<int> dp(N + 1, INF);
dp[0] = 0;  // dp[i] = i까지 도달하는 최소 비용

for (int i = 0; i < N; ++i) {
    if (dp[i] == INF) continue;
    for (auto [next, cost] : transitions(i)) {
        dp[next] = min(dp[next], dp[i] + cost);
    }
}
배열·구간전처리 O(NM)

2차원 누적합

보이는 말
직사각형 내부 합을 Q번 질문
선택 조건
격자 값은 고정이고 서로 다른 범위의 합을 반복 계산한다.
실수 방지
1-indexed로 만들면 경계 분기가 사라진다. 포함-배제의 더하기/빼기 부호 확인.
2차원 누적합 최소 코드
for (int y = 1; y <= N; ++y)
    for (int x = 1; x <= M; ++x)
        ps[y][x] = a[y][x] + ps[y-1][x]
                   + ps[y][x-1] - ps[y-1][x-1];

// (y1,x1) ~ (y2,x2), 양 끝 포함
int sum = ps[y2][x2] - ps[y1-1][x2]
          - ps[y2][x1-1] + ps[y1-1][x1-1];
배열·구간O(log 범위 × 판정)

매개변수 탐색

보이는 말
최댓값의 최솟값, 최소 거리의 최댓값
선택 조건
답 후보 X에 대한 가능/불가능이 F…F T…T 또는 T…T F…F로 나뉜다.
실수 방지
구간 의미와 마지막에 남길 값부터 정한다. mid±1 갱신이 그 의미와 일치해야 한다.
가능한 최댓값 최소 코드
long long lo = MIN_VALUE, hi = MAX_VALUE;
long long answer = lo - 1;

while (lo <= hi) {
    long long mid = lo + (hi - lo) / 2;
    if (possible(mid)) {
        answer = mid;
        lo = mid + 1;   // 더 큰 답 시도
    } else {
        hi = mid - 1;
    }
}
배열·구간O(N)

투 포인터

보이는 말
연속 부분 수열, 합이 S 이상인 최소 길이
선택 조건
오른쪽을 늘리거나 왼쪽을 줄일 때 조건 값이 한 방향으로 변한다.
실수 방지
음수가 섞이면 합의 단조성이 깨질 수 있다. 정답 갱신 시점을 명확히 한다.
최소 길이 최소 코드
int left = 0, answer = INF;
long long sum = 0;

for (int right = 0; right < N; ++right) {
    sum += a[right];
    while (sum >= S) {
        answer = min(answer, right - left + 1);
        sum -= a[left++];
    }
}
그래프O((V+E) log V)

다익스트라

보이는 말
가중치가 있는 그래프의 최소 비용
선택 조건
모든 간선 가중치가 0 이상이고 한 시작점 최단 거리를 구한다.
실수 방지
최소 힙을 사용하고 꺼낸 거리가 최신 dist와 다르면 건너뛴다. 음수 간선에는 사용 금지.
최소 코드 열기
const long long INF = 4'000'000'000'000'000'000LL;
using P = pair<long long,int>;
priority_queue<P, vector<P>, greater<P>> pq;
vector<long long> dist(V, INF);
dist[start] = 0; pq.push({0, start});

while (!pq.empty()) {
    auto [cost, cur] = pq.top(); pq.pop();
    if (cost != dist[cur]) continue;
    for (auto [next, weight] : graph[cur]) {
        if (dist[next] <= cost + weight) continue;
        dist[next] = cost + weight;
        pq.push({dist[next], next});
    }
}
그래프거의 O(1)

Union-Find

보이는 말
같은 그룹인지 질문, 두 집합 합치기, 사이클 판별
선택 조건
경로 자체보다 연결 집합의 대표가 필요하고 연결 관계가 계속 추가된다.
실수 방지
find에 경로 압축을 넣고 루트끼리 합친다. 방향성이 있는 연결에는 그대로 쓰지 않는다.
최소 코드 열기
int parent[MAX_N], sz[MAX_N];

void init(int n) {
    for (int i = 0; i < n; ++i) {
        parent[i] = i;
        sz[i] = 1;
    }
}

int find(int x) {
    if (parent[x] == x) return x;
    return parent[x] = find(parent[x]);
}

bool unite(int a, int b) {
    a = find(a); b = find(b);
    if (a == b) return false;
    if (sz[a] < sz[b]) swap(a, b);
    parent[b] = a; sz[a] += sz[b];
    return true;
}
검색어와 일치하는 알고리즘이 없습니다.

기출을 이렇게 분류한다

풀이 회고가 아니라 선택 근거를 연습하는 예시입니다.

SWEA 1244 · 최대 상금

정해진 횟수만큼 두 자리 교환

숫자 길이가 작고, 매 단계 모든 두 자리 조합을 선택한다. 같은 숫자 상태라도 남은 교환 횟수가 다르면 별도 상태다.

작은 N → 모든 교환 선택 → 중복 상태 제거
백트래킹 + 깊이별 방문 집합
SWEA 1949 · 등산로 조성

격자 경로 → 추가 상태 1개 → 경로 원복
DFS + 백트래킹
SWEA 4013 · 특이한 자석

맞닿은 극에 따라 연쇄 회전

시간 순서 규칙 → 판정과 변경 분리
시뮬레이션
